# **App Name**: Algarrobo Landing

## Core Features:

- Hero Section: A landing page hero section to welcome visitors, display the logo, and communicate the core value proposition.
- Services Section: Highlight key services offered by Algarrobo Adult Day Care with concise descriptions and appealing visuals.
- About Section: Share the story, mission, and values of Algarrobo Adult Day Care to build trust and connection with potential clients.
- Contact Call-to-Action: Implement a clear and persuasive call-to-action, encouraging visitors to get in touch for inquiries or enrollment.

## Style Guidelines:

- Primary color: Warm brown (#A67B5B) to reflect stability, comfort, and earthiness.
- Background color: Desaturated brown (#E6D8CE) for a gentle, neutral backdrop that complements the brand's natural aesthetic.
- Accent color: Sage green (#97B47B) reminiscent of foliage, to give an impression of calm and growth.
- Font pairing: 'Alegreya' (serif) for headlines to create a feeling of vintage elegance, with 'PT Sans' (sans-serif) for body text to ensure readability.
- Use natural, line-art style icons to visually represent services, care aspects, and activities.
- Maintain a clean, spacious layout with clear sections for easy navigation and comfortable reading.
- Subtle transitions and hover effects to guide the user through the page.
